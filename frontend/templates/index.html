// ABOUT THE PROJECT

PhishShield

PhishShield is a Machine Learning-based phishing detection and prevention system developed as a Major Project at BMS Institute of Technology and Management, Bengaluru. It combines advanced feature extraction, supervised ML models, and Explainable AI (XAI) to identify malicious URLs and email content in real time — while giving users clear, understandable reasons behind every decision.

// HOW IT WORKS
01
Data Collection & Preprocessing
URLs and email samples collected from PhishTank, OpenPhish, and Kaggle. Data cleaned, normalized, and balanced using resampling techniques to handle class imbalance.
02
Feature Extraction
Three feature categories extracted — Lexical (URL length, special chars, keywords), Host-based (domain age, DNS, SSL), and Content-based (text patterns, hyperlink analysis).
03
ML Classification
Multiple algorithms trained and evaluated — Random Forest, SVM, Gradient Boosting. Best model selected based on Accuracy, Precision, Recall, and F1-Score metrics.
04
Risk Score Computation
Classification probabilities converted to a 3-tier threat level. Low risk → Safe. Medium → Warning. High → Blocked/Flagged as phishing.
05
Explainable AI (XAI)
SHAP (Shapley Additive Explanations) applied to generate reason-based alerts — clearly showing which URL features contributed most to the phishing verdict.
06
Real-Time Alerts & Logging
Results displayed instantly with prevention recommendations. All scans logged for monitoring, analysis, and model improvement over time.
