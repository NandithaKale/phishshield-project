      // ABOUT THE PROJECT

      PhishShield

      PhishShield is a Machine Learning-based phishing detection and prevention system developed as a Major Project at BMS Institute of Technology and Management, Bengaluru. It combines advanced feature extraction, supervised ML models, and Explainable AI (XAI) to identify malicious URLs in real time — giving users clear, understandable reasons behind every decision.

      SDG 9 — Industry & Innovation SDG 16 — Peace & Justice SDG 4 — Quality Education
      // HOW IT WORKS
      01
      Data Collection & Preprocessing
      URLs collected from PhishTank, OpenPhish, and Kaggle. Cleaned, normalized, and balanced using resampling techniques.
      02
      Feature Extraction (17 Features)
      URL length, dot/dash/slash counts, HTTPS status, @ symbol, digit count, suspicious keywords, risky TLDs, subdomain depth, domain digit presence, long URL flag.
      03
      ML Classification — Random Forest
      Model trained and saved as url_model.pkl. Loaded via joblib at runtime. Threshold set at 0.7 for phishing classification.
      04
      Risk Score Computation
      predict_proba() output converted to percentage. Below 70% → Safe. Above 70% → Phishing.
      05
      Explainable Alerts
      Feature values analyzed per URL and mapped to human-readable reasons shown in the Result page.
      06
      Flask REST API
      Frontend sends POST to /predict with the URL. Backend responds with is_phishing and confidence values.
