    // ABOUT THE PROJECT

    PhishShield

    PhishShield is a Machine Learning-based phishing detection and prevention system. It combines URL feature extraction, a Random Forest classifier, and Explainable AI to provide a prediction together with understandable feature contributions.

    SDG 9 — Industry & InnovationSDG 16 — Peace & JusticeSDG 4 — Quality Education
    // HOW IT WORKS
    01
    Data Collection & Preprocessing
    URLs are cleaned and prepared for supervised machine-learning training.
    02
    Feature Extraction — 17 Features
    URL length, punctuation counts, HTTP/HTTPS status, suspicious keywords, TLD, subdomain structure, domain digits and related URL properties.
    03
    ML Classification — Random Forest
    The trained Random Forest model returns a phishing probability through predict_proba(). The project uses a 0.7 phishing threshold.
    04
    Explainable AI — SHAP
    SHAP identifies the strongest feature contributions for the individual URL prediction and the frontend presents them as human-readable explanations.
    05
    Flask REST API
    The frontend sends a POST request to /predict and receives the prediction, confidence and XAI explanation.
